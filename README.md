# ⚙️ Automation Scripts

Welcome to my automation repository!  
This collection showcases my real-world DevOps and IT administration scripts, which are used for Azure, Windows, and CI/CD automation tasks.

---

## 🧠 About This Repository

These scripts were developed to simplify and automate repetitive DevOps and infrastructure operations such as:
- Managing Azure VMs and resources
- Monitoring and health checks
- Configuration management
- Log analysis and reporting
- System maintenance tasks

Each script is well-documented, modular, and ready to use in enterprise environments.

---

## 📂 Repository Structure

| Folder / Script | Description |
|------------------|-------------|
| `PS-Appcert_update.ps1` | Update the certificate in app service |
| `PS-appcertificatedetails.ps1` | Fetch app services certificate details |
| `PS-Disable_Cosmos_DB_Key_Access.ps1` | Disable Cosmos DB key access |
| `PS-Containercopy.ps1` | Copy container from one storage and another |
| `PS-azure_alertrules.ps1` | Fetch alert rules in azure |
